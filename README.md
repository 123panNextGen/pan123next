一款使用 **Dart/Flutter** 编写的第三方 123云盘 桌面客户端，采用 **Fluent UI** 设计风格，支持多平台运行（Windows / macOS / Linux / Android）。

> ⚠️ 本项目仍在早期开发阶段，功能尚不齐全，可能存在较多问题。

## ✨ 功能

| 功能 | 状态 |
|------|------|
| 用户名/密码登录 | ✅ |
| 二维码登录 | 🚧 计划中 |
| 文件浏览（面包屑导航） | ✅ |
| 文件列表（回收站） | ✅ |
| 新建文件夹 | ✅ |
| 文件下载（分片并行下载） | ✅ |
| 断点续传 | ✅ |
| 下载进度 & 速度显示 | ✅ |
| 外部 URL 下载 | ✅ |
| 文件上传 | 💡 准备中 |
| 快速编辑 | 💡 准备中 |
| 主题切换（亮色/暗色） | ✅ |
| 强调色自定义 | ✅ |
| 下载路径设置 | ✅ |
| Windows / macOS / Linux | ✅ |
| Android APK | ✅ |
